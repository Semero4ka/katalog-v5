КАТАЛОГ ОПТОВЫХ ЦЕН — версия 5 (корзина + заявки + накладные для 1С)

СОСТАВ АРХИВА
  index.html            — приложение целиком (каталог, корзина, заявки, накладная)
  data.js               — прайс: 42 категории, 3292 позиции (от 16.10.2026)
  sw.js, service-worker.js — офлайн-кэш (версия catalog-v5)
  manifest.webmanifest  — установка на главный экран
  icon-192.png, icon-512.png — иконки
  img/                  — сюда кладите фото товаров (см. соответствие-фото.xlsx)
  соответствие-фото.xlsx — таблица «товар → имя файла фото»

ЗАГРУЗКА НА GITHUB PAGES
  1. Создайте репозиторий (Public) и откройте Add file -> Upload files.
  2. Перетащите ВСЕ файлы из этой папки (папку img можно не грузить — она пустая
     и создастся сама, когда положите первый файл фото).
  3. Commit changes. Затем Settings -> Pages: Branch main, папка / (root), Save.
  4. Через 1-2 минуты сайт доступен по адресу https://логин.github.io/имя-репозитория/

ФУНКЦИИ
  - Поиск (по названию и цене), фильтры по категориям, сортировка, ленивая загрузка.
  - Корзина: количества с точностью до 0,001, удаление, пересчёт итога.
  - Заявки: форма (покупатель, телефон, комментарий), история хранится на устройстве,
    текст заявки копируется одним нажатием для отправки менеджеру.
  - Накладная «Реализация товаров»: печатная форма (Печать/PDF), выгрузка CSV для 1С,
    автосумма прописью, сквозная нумерация (с 35157), сохранение реквизитов.
  - Фото: положите файл в img/ с именем из таблицы соответствия — миниатюра появится сама.

ОБНОВЛЕНИЕ ЦЕН
  Замените data.js (Add file -> Upload files) и Commit. Версия кэша повышается в sw.js
  (catalog-v5 -> catalog-v6) только при изменении кода index.html.
