КАТАЛОГ ОПТОВЫХ ЦЕН — версия 6 (16.10.2026)
=============================================

Состав файлов:
  index.html            — приложение целиком (каталог, корзина, заявки, накладные)
  data.js               — прайс: 41 категория, 3291 позиция
  sw.js / service-worker.js — офлайн-кэш (версия catalog-v6)
  manifest.webmanifest  — настройки установки приложения
  icon-192.png, icon-512.png — иконки
  img/                  — папка для фото товаров (сейчас пустая, грузить не нужно:
                          создастся сама при загрузке первого фото)
  соответствие-фото.xlsx — таблица «товар → имя файла фото» (в репозиторий НЕ грузить,
                          держать у себя на компьютере/телефоне)

Загрузка на GitHub Pages:
  1. Add file -> Upload files
  2. Перетащить ВСЕ файлы из архива, кроме папки img и таблицы соответствия
  3. Commit changes
  4. Settings -> Pages -> Deploy from a branch, main, / (root), Save

Фото товаров:
  - Имя файла для каждого товара указано в таблице соответствия
    (а также показывается на карточке товара-заглушки в каталоге).
  - Файл кладётся в папку img:  img/pXXXXXXXX.jpg
  - Подходят форматы jpg / jpeg / png / webp — приложение само перебирает
    варианты, регистр букв не важен.
  - НЕ загружайте фото из iPhone в формате HEIC — конвертируйте в JPG.

Корзина и накладные:
  - «+ В корзину» у каждого товара, кнопка «🛒 Корзина» в шапке.
  - «Оформить заказ» -> форма (имя, телефон, комментарий) -> накладная.
  - В накладной правятся количество, единица (шт/кг) и цена, итог и сумма
    прописью пересчитываются сами. Номер начинается с 35157.
  - «🖨 Печать / PDF» — печатная форма «Реализация товаров».
  - «⬇ CSV для 1С» — файл с колонками Номер;Дата;Поставщик;Покупатель;
    № строки;Товар;Количество;Единица;Цена;Сумма + строка «Итого».
    В 1С: Файл -> Открыть (разделитель — точка с запятой).

Если после замены файлов что-то выглядит по-старому: полностью закройте
вкладки сайта и откройте снова (или откройте в режиме инкогнито).
