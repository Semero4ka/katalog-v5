КАТАЛОГ ОПТОВЫХ ЦЕН — версия 7 (16.10.2026)

СОСТАВ:
  index.html            — приложение (каталог + корзина + заявки + накладные)
  data.js               — прайс: 42 категории, 3294 позиции
  sw.js, service-worker.js — офлайн-кэш (версия catalog-v7)
  manifest.webmanifest  — настройки установки на телефон
  icon-192.png, icon-512.png — иконки
  соответствие-фото.xlsx — таблица: товар -> имя файла фото (держите на компьютере, в репозиторий НЕ загружать)

ЗАГРУЗКА НА GITHUB:
  1. Add file -> Upload files.
  2. Перетащите все файлы КРОМЕ соответствие-фото.xlsx и папки img (папка пустая, создастся сама с первым фото).
  3. Commit changes.
  4. Settings -> Pages -> Deploy from a branch -> main / (root) -> Save.

ФОТО ТОВАРОВ:
  Файл фото кладётся в папку img/ репозитория с именем из таблицы соответствия (например, img/p8e229195.jpg).
  Имя файла = таблица, товар -> имя. Фото появляется в каталоге автоматически.
  Клик по миниатюре открывает фото на весь экран (закрыть: × или тап по экрану).
  Если фото на карточке нет — под заглушкой 📷 показано нужное имя файла.

НАКЛАДНАЯ:
  После оформления заявки открывается редактор «Реализация товаров».
  Номер задаётся в настройках (по умолчанию 35157) и увеличивается автоматически.
  Печать/PDF — кнопка «🖨 Печать / PDF». CSV для 1С — кнопка «⬇ CSV для 1С».
  Поставщик и подпись «Отпустил» — кнопка «⚙ Подпись и поставщик».
